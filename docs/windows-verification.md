# Чек-лист проверки на Windows

Разработка велась на macOS: WPF-приложение и служба агента компилируются, серверная логика и клиентская библиотека покрыты автотестами,
но **интерфейс Desktop и установка агента как службы Windows не запускались**. Перед пилотом выполните этот чек-лист на Windows 10/11.
Отмечайте результат каждого пункта; любое отклонение — дефект этапа 5.

## 0. Подготовка

- [ ] Сервер запущен (`dotnet run --project src/DrawingFlow.Server` в режиме Development или опубликованная сборка), `/health/ready` → `Healthy`.
- [ ] Desktop собран: `dotnet publish src/DrawingFlow.Desktop -c Release -r win-x64 --self-contained false -o publish/desktop`.
- [ ] Агент собран: `dotnet publish src/DrawingFlow.Agent -c Release -r win-x64 --self-contained false -o publish/agent`.
- [ ] В организации есть проект, пользователи с ролями Инженер, Проверяющий, Руководитель проекта, Наблюдатель.

## 1. Вход

- [ ] Окно входа открывается по центру экрана, шрифты и русские подписи отображаются корректно при масштабе 100 % и 150 %.
- [ ] Адрес `http://имя-сервера` (не localhost) отклоняется с объяснением про TLS; `http://localhost:5080` и `https://…` принимаются.
- [ ] Кнопка «Проверить» показывает версию сервера; при недоступном сервере — понятная ошибка.
- [ ] Неверный пароль → «Неверный логин или пароль.»; успешный вход открывает главное окно и закрывает окно входа.
- [ ] «Запомнить меня» выключено → после перезапуска приложения снова окно входа; включено → главное окно открывается сразу.
- [ ] Вход пользователем с временным паролем: показывается обязательный диалог смены пароля; закрытие окна крестиком возвращает к окну входа.

## 2. Главное окно и навигация

- [ ] Переключение организации в левой панели перезагружает текущую страницу; у пользователя одной организации список содержит один элемент.
- [ ] Пункты меню соответствуют правам: «Агенты» видят только администраторы организации, «Журнал аудита» — администраторы, «Администрирование» — администратор сервера.
- [ ] Строка состояния показывает зелёный индикатор; при остановке сервера и обновлении страницы — красный индикатор и сообщение об отсутствии связи, кнопка «Повторить» работает после запуска сервера.
- [ ] Истечение сессии (отзовите все сессии сменой пароля с другого компьютера) приводит к окну входа с сообщением.

## 3. Проекты и участники

- [ ] Поиск по кириллице, фильтр статуса, сортировка щелчком по заголовкам «Код», «Название», «Изменён», пагинация (создайте > 50 проектов или уменьшите размер страницы в коде для проверки).
- [ ] Создание проекта администратором; инженер кнопки «Создать проект» не видит.
- [ ] Карточка проекта: изменение названия/описания/статуса, добавление участника из списка участников организации, смена роли, удаление с подтверждением.
- [ ] Участники организации: добавление по логину, создание пользователя (флаг «Требовать смену пароля»), смена роли, удаление; попытка понизить последнего владельца даёт понятную ошибку.

## 4. Документы и версии

- [ ] Страница «Документы»: выбор проекта, поиск по шифру и наименованию, фильтр раздела и статуса, сортировка, пагинация, пустое состояние.
- [ ] Регистрация документа; дубликат шифра → ошибка 409 с русским текстом в диалоге.
- [ ] Загрузка версии: выбор файла > 100 МБ показывает прогресс; повтор загрузки того же файла создаёт новую версию только при изменении содержимого.
- [ ] Загрузка файла с кириллицей в имени и пробелами; имя сохраняется в истории версий.
- [ ] «Открыть» запускает связанное приложение (например, PDF/DWG); «В папке» открывает Проводник с выделенным файлом в `%LOCALAPPDATA%\DrawingFlow\cache`.
- [ ] «Скачать…» с выбором места; «Сравнить с текущей» показывает различия метаданных.
- [ ] Архивирование документа руководителем: кнопки загрузки исчезают; восстановление возвращает их.
- [ ] Изменение метаданных двумя пользователями одновременно: второй получает «Данные были изменены другим пользователем».

## 5. Согласование

- [ ] Инженер: «Отправить на проверку» — список кандидатов содержит проверяющих и руководителей, выбор нескольких, срок, поручение.
- [ ] Проверяющий: на главной и на странице «Задачи» видна задача; «Вернуть» без комментария недоступно; с комментарием документ переходит в «Требует доработки», инженер получает задачу доработки.
- [ ] Инженер загружает новую версию: статус «В работе», задача доработки закрыта, старая версия «Заменена».
- [ ] Повторная отправка, согласование, «Выпустить» руководителем; у инженера кнопки выпуска нет.
- [ ] История решений в карточке документа содержит оба решения с комментариями и авторами.

## 6. Агент

- [ ] Администратор: «Зарегистрировать агента», ключ копируется кнопкой; повторно ключ не отображается.
- [ ] На рабочей станции от имени администратора: `DrawingFlow.Agent.exe register --server https://… --key …` → «зарегистрирован», файл `%ProgramData%\DrawingFlow\Agent\agent.credential` создан и не читается как текст.
- [ ] `sc.exe create "DrawingFlow Agent" binPath= "…\DrawingFlow.Agent.exe" start= auto` и запуск; в журнале событий Windows появляется источник «DrawingFlow Agent»; файл `%ProgramData%\DrawingFlow\Agent\logs\agent-ГГГГММДД.log` пишется.
- [ ] В Desktop добавлена папка наблюдения (локальная и сетевая `\\server\share`); агент отмечен «на связи» в течение минуты.
- [ ] Копирование файла `АР-01_план.dwg` в папку → через окно стабильности (5 с) версия появляется в документе АР-01 ровно один раз; повторное сохранение файла без изменений версию не создаёт.
- [ ] Файл, открытый в AutoCAD/Word (блокировка), загружается после закрытия; `~$`-файлы игнорируются.
- [ ] Файл с неизвестным шифром попадает в «Синхронизация» со статусом «Требует разрешения»; «Сопоставить» с документом → агент загружает версию в течение интервала сердцебиения.
- [ ] Остановка службы с незавершёнными операциями и повторный запуск: операции продолжаются, дубликатов версий нет.
- [ ] Отключение сети на рабочей станции: операции переходят в «Ожидает» с ростом задержки; после восстановления сети загружаются.
- [ ] Отзыв ключа в Desktop: агент в журнале сообщает об отзыве, загрузки прекращаются; повторная регистрация новым ключом восстанавливает работу.

## 7. Эксплуатация

- [ ] `DrawingFlow.Server --migrate` на пустой базе создаёт схему и администратора с временным паролем; первый вход требует смену пароля.
- [ ] `DrawingFlow.Server --verify-storage` после восстановления из копии выводит отсутствующие объекты (удалите один файл хранилища для проверки) и завершается кодом 3.
- [ ] За обратным прокси (`ReverseProxy:Enabled=true`, `KnownProxies`) адрес клиента в журнале аудита соответствует реальному адресу рабочей станции.
- [ ] Журналы Desktop (`%LOCALAPPDATA%\DrawingFlow\logs`) и агента не содержат паролей, токенов и ключей.
