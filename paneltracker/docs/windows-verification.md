# Panel Tracker — ручная проверка на Windows

WPF-приложение на macOS не запускается, поэтому ниже — что нужно проверить вручную на Windows 10/11.
Автоматически проверено на macOS: сборка решения без ошибок и предупреждений (Debug и Release),
49 xUnit-тестов ядра, публикация одним exe (`dotnet publish -r win-x64`).

## Подготовка

1. Из папки с `PanelTracker.sln`: `dotnet run --project src/PanelTracker.App` **или** запуск опубликованного `PanelTracker.exe`.
2. Создайте пустую папку, например `C:\Temp\Panels`.
3. В программе: «Выбрать папку проекта…» → `C:\Temp\Panels` → «Создать папки статусов».
   - [ ] В папке появились `01 Ready to Check` … `06 Locked`.
   - [ ] Рядом с exe появился `settings.json` с `rootFolder` = выбранная папка.
   - [ ] В строке состояния: «Слежение: включено».
4. Положите в `01 Ready to Check` файлы `N001.pdf` … `N030.pdf`, `W046.pdf`, `S177.pdf`; в `04 Sent to client` — `N100.pdf`, `N101.pdf`
   (подойдут любые PDF или переименованные копии одного PDF).

## 1. Доска плиток

- [ ] Плитки появились автоматически (без нажатия «Обновить») в течение 1–2 с после копирования.
- [ ] Цвет плитки соответствует статусу (оранжевые в «Готово к проверке», зелёные в «Отправлено заказчику»).
- [ ] Порядок: N1, N2 … N30, N100, N101, S177, W046 (числовая сортировка, не N1, N10, N100).
- [ ] Поиск «N02» оставляет N020–N029; «Сбросить» возвращает всё.
- [ ] Фильтр «Статус» = «Отправлено заказчику» → только N100, N101; «Показано: 2 из 34».
- [ ] Щелчок по счётчику статуса ставит тот же фильтр, повторный щелчок снимает.
- [ ] Выделение: щелчок, Ctrl+щелчок, Shift+щелчок, Ctrl+A; «выделено: N» в строке фильтров меняется.
- [ ] Выделите несколько плиток, затем включите фильтр, скрывающий часть из них: «выделено» уменьшилось, скрытые плитки
      не участвуют в командах контекстного меню; после «Сбросить» они не выделены.
- [ ] Выделение и прокрутка доски сохраняются при периодическом пересканировании (подождите 10–20 с, ничего не меняя).
- [ ] Наведение на плитку показывает подсказку с файлом, датой, статусом.
- [ ] 300+ файлов (скопируйте N001–N030 десять раз с разными именами): доска прокручивается, не тормозит.

## 2. Счётчики

- [ ] «Всего панелей» = число PDF (34).
- [ ] По каждому статусу количество и процент; сумма процентов ≈ 100.
- [ ] Полоса прогресса: «Отправлено заказчику 2 из 34 (6%)».

## 3. Слежение за папками

- [ ] В проводнике перетащите `N005.pdf` из `01 Ready to Check` в `03 Ready to Send`: плитка перекрасилась через 1–2 с.
- [ ] Переименуйте в проводнике `N006.pdf` → `N006_R2.pdf`: на плитке появилось «R2».
- [ ] Удалите файл в проводнике: плитка исчезла. Верните — появилась.
- [ ] На вкладке «История» появилась запись «Обнаружено (вне программы)», кто = «проводник», откуда/куда верные.
- [ ] Кнопка «Обновить» и F5 работают; статусная строка показывает время последнего сканирования.
- [ ] Папка на сетевом диске (если есть): события приходят либо подхватываются периодическим опросом (≤ 10 с).

## 4. Контекстное меню (одиночное и множественное выделение)

- [ ] Правый щелчок по невыделенной плитке выделяет только её; по одной из выделенных — сохраняет выделение.
- [ ] «Открыть файл» открывает PDF в программе по умолчанию; двойной щелчок — то же.
- [ ] «Открыть расположение файла» открывает проводник с выделенным файлом.
- [ ] Выделите N001–N003 → «Перевести в статус» → «Готово к отправке»: три файла физически переместились в `03 Ready to Send`,
      плитки перекрасились, в строке состояния «перемещено 3, пропущено 0, ошибок 0».
- [ ] Повторите для панели, уже находящейся в целевом статусе: «пропущено 1», файл не тронут.
- [ ] Положите копию `N010.pdf` в `03 Ready to Send` и переведите N010 туда из программы: сообщение об ошибке «уже есть файл»,
      исходный файл остался на месте, ничего не перезаписано.
- [ ] Выберите несуществующую/недоступную папку проекта (например, отключённый сетевой диск): сообщение об ошибке, доска пуста,
      в `settings.json` остался прежний `rootFolder`.
- [ ] «Заблокировать (HOLD)» → файл в `06 Locked`, на плитке замок. «Снять блокировку» → файл вернулся в прежнюю папку
      (из истории), не в первую попавшуюся.
- [ ] «Отметить „Проблема“…» → диалог с комментарием → файл в `05 Problem`, плитка красная с «!», комментарий виден в подсказке
      и в «Истории». Повторная отметка панели в «Проблеме» только обновляет комментарий.
- [ ] «Отмена» в диалоге комментария ничего не перемещает.
- [ ] Все команды недоступны (серые), когда ничего не выделено.

## 5. Группы

- [ ] Вкладка «Группы»: по умолчанию A: Solid panel, B: Spandrel, C: HM door panel, D: Corner panel.
- [ ] На доске выделите несколько плиток → «Добавить в группу» → A: в углу плиток появилось «A», `groups.json` создан в корне проекта.
- [ ] Фильтр «Группа» = «A: Solid panel» показывает только их; «Без группы» — остальные.
- [ ] «Убрать из группы» убирает метку; «Убрать выбранную панель» на вкладке «Группы» — то же.
- [ ] «Добавить…» (ключ E, название Parapet), «Переименовать…», «Удалить» (с подтверждением) работают; фильтр по группе обновился.
- [ ] Закройте и откройте программу: группы сохранились.

## 6. История

- [ ] Таблица: когда, кто (имя учётной записи Windows), панель, файл, откуда, куда, действие, комментарий; новые записи сверху.
- [ ] Фильтр по панели «N001» оставляет только её записи.
- [ ] `history.jsonl` в корне проекта — по одной JSON-строке на событие; после ручной порчи одной строки программа читает остальные.

## 7. Дубликаты

- [ ] Положите `N020.pdf` одновременно в `01 Ready to Check` и `04 Sent to client`: в счётчиках появился «Дубликаты: 1»,
      на плитке «⚠», на вкладке «Дубликаты» две строки с путями.
- [ ] «Открыть расположение» в строке открывает проводник на нужном файле.
- [ ] Удалите один из файлов — дубликат исчез.

## 8. Ревизии

- [ ] `N021.pdf` в `04 Sent to client` и `N021_R2.pdf` в `01 Ready to Check`: одна плитка N021 с «R2», статус «Готово к проверке»,
      помечена как дубликат (файлы в двух папках).
- [ ] «Перевести в статус» перемещает только `N021_R2.pdf`; `N021.pdf` остаётся.
- [ ] Варианты `N021-R3.pdf`, `N021 R4.pdf`, `N021_rev5.pdf`, `N021 (R6).pdf` распознаются как N021 с ревизией.

## 9. Статистика

- [ ] Вкладка «Статистика»: строки = группы (A–D), «Без группы», «Всего»; столбцы = статусы в цветах, «Всего», «Отправлено».
- [ ] Добавьте N001 в группы A и B: в обеих строках +1; «Всего» не удваивает панель.
- [ ] Переведите панель группы A в «Отправлено заказчику»: в строке A изменились ячейки и процент «Отправлено».

## 10. Настройки

- [ ] «Открыть settings.json» открывает файл в редакторе по умолчанию.
- [ ] Измените цвет статуса и имя папки, «Перечитать настройки»: цвета и таблица статусов обновились; при несуществующей папке
      в строке состояния «Нет папок: …», «Создать папки статусов» создаёт её.
- [ ] Сломайте JSON (лишняя запятая): при запуске — предупреждение и настройки по умолчанию, программа не падает.
- [ ] Два статуса с одной папкой → «Перечитать настройки» показывает ошибку «Папка … назначена нескольким статусам».
- [ ] Удалите статус с ролью `hold` → команда «Заблокировать» сообщает об отсутствии статуса, не падает.

## 11. Публикация

- [ ] `dotnet publish ... -r win-x64` → `PanelTracker.exe` запускается на машине без установленного .NET.
- [ ] Вариант `--self-contained false` запускается при установленном .NET Desktop Runtime 10.
- [ ] Масштабирование 125–150 % (DPI): текст на плитках не размыт.
